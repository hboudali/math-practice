Lesson 1.1 · Concept

Absolute Value & Rational Numbers

Absolute value is the distance between a number and zero on a number line. Distance is always positive (or zero), so absolute value is always ≥ 0.

We write it with bars: |−5| = 5 |+5| = 5

Opposite numbers have the same absolute value: |−5| = |+5| = 5

Example — Comparing Absolute Values

Compare |−8.5| and |+6.2|.
|−8.5| = 8.5  ·  |+6.2| = 6.2  →  8.5 > 6.2, so |−8.5| > |+6.2|.
Even though −8.5 < +6.2, its absolute value is larger.

Lesson 1.2 · Concept

Additive Inverse

Two numbers are additive inverses if they add up to zero. Every number's additive inverse is its opposite.

a + (−a) = 0   7 + (−7) = 0   −3.5 + 3.5 = 0

Example

Mia earns $12 babysitting. She spends $12 on a book.
→ +12 + (−12) = 0  ·  The additive inverse of +12 is −12.

Key Rule

The additive inverse of n is −n. The additive inverse of −7 is +7.

Adding & Subtracting Rational Numbers

Two key rules:

① Fractions — find the LCD, convert both fractions, then add/subtract numerators.
② Decimals — align the decimal points so place values line up, then add/subtract normally.

Example from Lesson 1.3

Corey bought 4⅗ oz cashews and 3¹/₁₀ oz pistachios.
LCD of 5 and 10 is 10: convert 3/5 → 6/10.
4⁶/₁₀ + 3¹/₁₀ = 7⁷/₁₀ oz

Lesson 1.4 · Concept

Adding Positive and Negative Numbers

Use the number line — direction and distance determine the sum:

pos + pos → farther right (more positive)
neg + neg → farther left (more negative)
pos + neg → the number with the larger absolute value wins the sign

Example — Estimating

Is −4 a reasonable estimate for 24.24 + (−27.8)?
Round: 24 + (−28) = −4. Yes — the actual answer is −3.56, so −4 is close! ✓

Lesson 1.5 · Concept

Subtracting Positive and Negative Numbers

Subtracting is the same as adding the additive inverse of the second number:

a − b = a + (−b)   a − (−b) = a + b

Key Insight

Subtracting a negative is the same as adding its absolute value.
4 − (−7.5) = 4 + 7.5 = 11.5

Common Mistake — Jamal's Error

Jamal wrote: 10 − (−10) = 10 − 10 = 0 ✗
Correct: 10 − (−10) = 10 + 10 = 20 ✓

Adding with Mathematical Properties

Three properties let you rearrange and regroup numbers to add rational numbers more efficiently:

Strategy — Group Additive Inverses First

−1 + 11 + 13 + (−5) + (−7)
→ Regroup: {−1 + (−5) + (−7) + 13} + 11  →  0 + 11 = 11

Lesson 1.7 · Concept

Rational Numbers in the Real World

Apply everything from Chapter 1 — absolute value, additive inverses, adding/subtracting fractions and decimals, and mathematical properties — to solve real-world problems.

Strategy

① Read carefully — identify what is added vs subtracted.
② Use positive numbers for gains/increases and negative for losses/decreases.
③ Group additive inverses to simplify the arithmetic.

Example — Bank Balance

Lynn starts with $64. After writing checks, her balance is −$13.
Total checks = 64 − (−13) = 64 + 13 → wait, no: 64 − x = −13 → x = 64 + 13 = $77
